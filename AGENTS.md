# Agent guidance

- This is a single-package React 19 + Vite app; `src/main.jsx` mounts `src/App.jsx`, which owns the routes and shared theme state. Page sections live in `src/components/` and global styles in `src/App.css`.
- Use `npm install` to install dependencies, `npm run dev` for local development, `npm run build` to verify the production build, `npm run preview` to serve `dist/`, and `npm run lint` for ESLint. There is no test or typecheck script configured.
- Public images and downloadable files belong in `public/` and are served/copied from the site root (for example, use `/filename.png` in the app). `dist/` is generated by Vite; edit source/public files rather than build output.
- ESLint covers JS/JSX and treats unused variables as errors; `dist/` is excluded. Follow the existing ES module and JSX component patterns.
